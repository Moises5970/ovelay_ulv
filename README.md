# 📘 Manual Técnico: Overlysi

Este sistema tiene como proposito facilitar y hacer mas accesibles el manejo de overlays para transmiciones. Tiene un control en donde se pueden configurar los textos y mandar las platillas necesarias y se espera que solo accedan las que sean necesarias y una salida que puede ponerse como una capa por encima.
